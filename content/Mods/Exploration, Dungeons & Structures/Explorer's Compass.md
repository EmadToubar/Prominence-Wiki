# Explorer's Compass

By ChaosTheDude — a craftable compass that locates and points to the nearest instance of any generated structure (village, stronghold, ocean monument, any of the pack's added structures, etc.), with the direction/HUD overlay shown even while chat is open. On this server it's configured generously: unlimited durability (`compassDurability: 0`, meaning it never breaks), zero XP cost per search (`defaultXpLevel: 0`), a 10,000-block max search radius, and up to 100 repeated searches for the next instance of an already-found structure type. No structures are blacklisted from search. Players in creative/cheat mode or who are opped can also teleport directly to a located structure.

## Anticipated questions

**Q: How do I find a specific structure?**
A: Craft the Explorer's Compass, open it, pick any generated structure type (village, stronghold, monument, or any of the pack's added structures) and it points to the nearest instance — the HUD overlay shows even with chat open.

**Q: Does it break or cost XP?**
A: No — on this server it's set to unlimited durability (never breaks) and zero XP cost per search, with a 10,000-block max search radius and up to 100 repeat searches for the next instance.

**Q: Can I teleport to what I find?**
A: Only players in creative/cheat mode or who are opped can teleport directly to a located structure; normal survival players must travel there.

**Q: What about finding biomes instead?**
A: Use its sister mod [[Nature's Compass]] for biomes.
