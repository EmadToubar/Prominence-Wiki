# The Lost Castle

Jar file: `tlc-fabric-1.0.1-1.20.X.jar` (mod id `tlc`, by Jack Bagel and GilVoisard). Introduces a single enormous, hand-built castle structure that generates rarely in the world — findable with the help of a map given by a journeyman-level cartographer villager, echoing vanilla's Woodland Mansion/Ocean Monument explorer-map convention rather than requiring a search tool. No server-side config override exists for it; it runs on shipped defaults.
