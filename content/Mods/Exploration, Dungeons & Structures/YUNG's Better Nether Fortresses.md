# YUNG's Better Nether Fortresses

**YUNG's Better Nether Fortresses** (jar `YungsBetterNetherFortresses-1.20-Fabric-2.0.6.jar`, by YUNGNICKYOUNG & Acarii) is a "complete redesign of Minecraft's Nether Fortresses" — expanding the maze-like vanilla fortress bridge network into a more deliberately laid-out structure with distinct rooms rather than long repeating corridor segments.

Server config (`config/betterfortresses-fabric-1_20.toml`) sets `disableVanillaFortresses = true`, so every Nether Fortress on this world is this mod's redesigned version — there is no vanilla fallback. No other tuning is present beyond that toggle.

## Anticipated questions

**Q: What's different about the fortress?**
A: The maze-like vanilla bridge network becomes a more deliberately laid-out structure with distinct rooms rather than long repeating corridor segments. See [[Finding Structures & Exploration]] and [[Bosses & Recommended Levels]].

**Q: Will I find vanilla fortresses too?**
A: No — `disableVanillaFortresses = true`, so every Nether Fortress on this world is this mod's redesigned version.

**Q: Is anything else tuned?**
A: No — no other tuning is present beyond that toggle.
