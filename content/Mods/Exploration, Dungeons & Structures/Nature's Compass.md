# Nature's Compass

Explorer's Compass's sister mod, also by ChaosTheDude — instead of structures, it locates the nearest instance of a chosen **biome** (a genuinely useful pairing given how many biome-adding mods run in this pack: Regions Unexplored, Geophilic, River Redux, Swampier Swamps, and others). Configured to match its sibling: unlimited compass durability, zero XP cost per search, HUD coordinate display enabled, and biome names auto-fixed for readability (e.g. "ForestHills" renders as "Forest Hills"). No biomes are blacklisted from search.

## Anticipated questions

**Q: What does Nature's Compass find?**
A: The nearest instance of a chosen biome — useful given how many biome mods run here (Regions Unexplored, Geophilic, River Redux, Swampier Swamps). See [[Finding Structures & Exploration]].

**Q: Does searching cost anything?**
A: No — it's configured with unlimited compass durability and zero XP cost per search.

**Q: Are any biomes excluded from the search?**
A: No — no biomes are blacklisted from search.

**Q: How does it relate to Explorer's Compass?**
A: It's the sister mod by the same author ([[Explorer's Compass]]) and is configured to match; Explorer's Compass locates structures, Nature's Compass locates biomes.
