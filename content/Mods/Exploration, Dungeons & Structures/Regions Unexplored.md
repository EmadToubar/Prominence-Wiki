# Regions Unexplored

**Regions Unexplored** (jar `RegionsUnexploredFabric-0.5.6+1.20.1.jar`, by UHQ_Games with contributions from KirboSoftware and Loxi) is a large Overworld biome-expansion mod — its own description says "almost 70 new biomes," and the server's config file (`config/regions_unexplored/regions_unexplored-common.toml`) confirms **82 individual biome toggles**, essentially all left at their default `true`. The added biomes range from familiar-sounding variants (Boreal Taiga, Cold Boreal Taiga, Frozen Pine Taiga, Cold River, Gravel Beach, Grassy Beach) to genuinely novel terrain types: Fungal Fen, Hyacinth Deeps, Mycotoxic Undergrowth, Scorching Caves, Redstone Hell, Bayou, Joshua Desert, Baobab Savanna, Rocky Reef, Tropical River, Willow Forest, Eucalyptus Forest, Bamboo Forest, Smouldering Woodland, Redwoods, Towering Cliffs, Mauve Hills, Outback, Arid Mountains, Highland Fields, Alpha Grove, Barley Fields, Orchard, Temperate Grove, Clover Plains, Rainforest, and more.

The only feature disabled in config is `toggle_custom_regions = false` — an unrelated experimental "custom regions" system, not a biome. Every actual biome toggle is on, so this pack runs Regions Unexplored at essentially full breadth. The mod also ships several `regions_unexplored-secondary-region-*.toml.bak` files (disabled/backed-up secondary region configs), suggesting the region-layering system beyond the primary/common config isn't actively customized here either.
