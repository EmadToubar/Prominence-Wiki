# Philip's Ruins

**Philip's Ruins** (jar `PhilipsRuins1.20.1-5.7-Fabric.jar`, by Philip) is a pure structure-generator mod — its own description is blunt: "It adds over 200 new structures to your Minecraft world." Counting the actual `.nbt` structure files packed into the jar confirms **287 individual structures**, organized into a wide range of `structure_set` definitions (e.g. `ancient_crypt`, `ancient_dungeon`, and many more) so they spread across different biomes and generation rules rather than piling into one category.

This server also loads a **Philip's Ruins × Better End compatibility datapack** (`config/paxi/datapacks/ichphilipp-s-endcity-better-end-1-18-1.zip`, delivered through the Paxi datapack-loader mod), which reworks one of Philip's Ruins' End-city-style structures to fit properly into Better End's custom End biomes rather than vanilla End terrain. No standalone `config/` file exists for the mod itself, so its structure rarity/spawn weighting runs at the values baked into that compat-aware default.

## Anticipated questions

**Q: How many structures does this add, and where?**
A: Over 200 by its description — 287 actual `.nbt` files — spread across many biomes via a wide range of `structure_set` definitions (e.g. `ancient_crypt`, `ancient_dungeon`). See [[Finding Structures & Exploration]].

**Q: Does it work with Better End's custom End?**
A: Yes — the server loads a Philip's Ruins × Better End compat datapack (via Paxi) that reworks one of its End-city-style structures to fit Better End's End biomes rather than vanilla End terrain.

**Q: Is its spawn rarity customized on this server?**
A: No standalone `config/` file exists for the mod, so structure rarity/spawn weighting runs at the baked-in defaults.
