# Explorations

A lightweight structure-generation mod by Tristan Kechlo (`tristankechlo`) that adds "more vanilla style structures to the game" — new points of interest built to blend with Mojang's own worldgen aesthetic rather than standing out as an obvious add-on, unlike the more elaborate hand-built structure packs in this pack (Philip's Ruins, Moog's Voyager Structures). It ships as pure structure/worldgen code with no dedicated block or item set of its own, and no server-side config override is present — it runs on its shipped defaults.

## Anticipated questions

**Q: What does Explorations add?**
A: More vanilla-style structures (points of interest) built to blend with Mojang's own worldgen aesthetic rather than stand out — it ships no blocks or items of its own.

**Q: How do I find its structures?**
A: Use [[Explorer's Compass]] to locate them; the mod runs on shipped defaults with no server tuning.
