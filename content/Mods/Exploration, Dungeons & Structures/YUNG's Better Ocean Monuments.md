# YUNG's Better Ocean Monuments

**YUNG's Better Ocean Monuments** (jar `YungsBetterOceanMonuments-1.20-Fabric-3.0.4.jar`, by YUNGNICKYOUNG & Tera) is a "complete redesign of Minecraft's ocean monuments," reworking the vanilla monument's repetitive prismarine-block maze into more varied, deliberately-built underwater rooms while keeping the Elder Guardian/Guardian threat and sponge-room reward intact conceptually.

Server config (`config/betteroceanmonuments-fabric-1_20.toml`) sets `disableVanillaMonuments = true`, so vanilla ocean monuments no longer generate — every monument on this world is this mod's version. No other tuning is configured.

## Anticipated questions

**Q: What does this rework?**
A: The vanilla monument's repetitive prismarine maze becomes more varied, deliberately-built underwater rooms, keeping the Elder Guardian/Guardian threat and sponge-room reward intact conceptually. See [[Bosses & Recommended Levels]].

**Q: Will vanilla monuments still generate?**
A: No — `disableVanillaMonuments = true`, so every monument on this world is this mod's version.

**Q: Is anything else configured?**
A: No — no other tuning is configured.
