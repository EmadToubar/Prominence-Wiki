# Tech Reborn

Tech Reborn (v5.8.14, built on the shared RebornCore library) is a complete, self-contained classic tech tree in the IC2/GregTech lineage: ore doubling via an Industrial Grinder, tiered generators and dynamos, machine upgrades, and its own Reactor system alongside a craftable Nuke (server-configured to a 40-block radius and 400-tick fuse, though it can be disabled outright via config). Its signature late-game resource is UU-Matter — literally Universal Matter synthesized from raw energy through a Matter Fabricator/Replicator, letting players convert surplus power directly into scarce materials. Machines use the IC2-style "dot side" energy convention (`IC2TransformersStyle = true`), where the marked face accepts input and the rest of the block outputs.

In this pack's Quest Book, Tech Reborn is chapter 1 of 7 (`tech_reborn.snbt`, 456 quests, icon `techreborn:uu_matter`) — the very first tech tree the book points players toward, with its opening quest subtitled "Welcome to Tech Reborn! A tech mod that provides options for power power generation, power storage, bulk item storage, tools and the creation of materials from energy and scrap." That ordering, combined with [[Applied Energistics 2]]'s built-in `PowerRatios.TechReborn = 2.0` energy-conversion setting, suggests Tech Reborn is meant as an accessible on-ramp tech tree that plugs cleanly into an AE2 network once players outgrow it.
