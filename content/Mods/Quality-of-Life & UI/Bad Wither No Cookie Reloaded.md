# Bad Wither No Cookie Reloaded

A small client-side sound-muting utility (jar `bwncr-fabric-1.20.1-3.17.2.jar`, package `com.kreezcraft.badwithernocookiereloaded`). Lets you individually silence specific game sounds that some players find grating: the Wither's ambient noise, the Wandering Trader, the Ender Dragon, thunder/lightning, plus a custom "Silence Us" list where you can add any other sound event by ID (e.g. `entity.sheep.step`) via the `/listen` command.

**Correction worth flagging:** earlier documentation for this pack (including this vault's original Dimensions & Space Travel category note) assumed this jar's `bwncr` filename prefix meant "Better Nether." It does not — the real Better Nether mod ships in a separate jar (`better-nether-9.0.10.jar`, id `betternether`) and is documented at [[Better Nether]]. This mod is unrelated to dimension content entirely; it's purely a sound-muffling QoL tool, functionally similar to [[Extreme Sound Muffler]] but scoped to a specific short list of sounds rather than arbitrary mute/volume control.
