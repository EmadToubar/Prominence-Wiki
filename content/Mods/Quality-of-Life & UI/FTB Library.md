# FTB Library

FTB Library (`ftblibrary`, v2001.2.9, by the FTB Team) is the shared foundational code and UI toolkit that every other FTB mod in the pack is built on — it provides the common GUI framework, config system, and utility code that [[FTB Quests]] and [[FTB Teams]] both require (`ftblibrary >=2001.2.1` / `>=2001.2.0` respectively) to run at all. It adds nothing directly visible to players by itself; its entire purpose is being the plumbing underneath the mods that are visible.
