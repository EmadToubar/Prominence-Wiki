# Highlight

Highlight (ThatGravyBoat, `highlight`, v2.0.1) is a small visual-polish mod that replaces the rigid, boxy block-selection outline vanilla uses on certain blocks with shapes that actually follow the block's real geometry — stairs, slabs, fences, and similar angled/partial blocks get a selection highlight that matches their model instead of a plain cube. It carries no user-facing configuration; it just changes rendering. Depends on Resourceful Lib (bundled) and ships an optional "Highlight Extended" companion resource pack for further-refined shapes. Note there is a separate, similarly-named `Highlighter` mod in this pack's mods folder — that one is currently disabled (`.jar.disabled`) and is a different mod entirely.
