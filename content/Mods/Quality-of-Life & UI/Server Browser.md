# Server Browser

Server Browser (`serverbrowser`, Thonk, v1.3.1) adds an in-game browser for finding other servers running the same modpack, pulled from minecraft.multiplayerservers.net. It's pre-configured for Prominence II specifically: `config/ServerBrowser/serverbrowser.json` sets `modPackFilter: "Prominence II [RPG]"` (so the browser only lists other Prominence II servers), a `bisectPackID` of `19073`, and an official server entry pointing at `prom2.moddedmc.net` that gets pinned to the top of the list as "Featured." This server itself (`a private address`) isn't in that official list — it's a private whitelist-only instance — so the feature mainly surfaces *other* public Prominence II communities to players browsing from here.
