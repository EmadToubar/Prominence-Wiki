# Macaw's Holidays

Macaw's Holidays (Sketch Macaw and Sketch Peachy) is a themed seasonal-decoration entry in the Macaw's family of building mods, adding **250+ Christmas decorations and 80+ Halloween-themed decorations** per its own description — 338 lang entries in total confirm a large, dedicated catalog rather than a handful of token items. It's the mod to reach for if anyone wants to deck out a build for a holiday event: think string lights, ornaments, wreaths, and festive furniture variants for Christmas, and jack-o'-lanterns, cobwebs, and spooky decor variants for Halloween, layered on top of the wood-type-variant pattern common to the rest of this category.

No config file ships for it here, so it runs with all content available by default year-round rather than being date-gated.

## Anticipated questions
**What does it add?** A large seasonal-decoration catalog — 250+ Christmas decorations (string lights, ornaments, wreaths, festive furniture variants) and 80+ Halloween decorations (jack-o'-lanterns, cobwebs, spooky variants), 338 lang entries in total.

**Are the decorations only available on their real-world dates?** No — no config file ships for it here, so all content is available by default year-round rather than being date-gated.

**When would I use it in a build?** It's the mod to reach for when decking out a build for a holiday event, layered on top of the wood-type-variant pattern shared with the rest of this category (pairs with [[Handcrafted]] and [[Chipped]]).
