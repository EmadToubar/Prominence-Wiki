# KleeSlabs

KleeSlabs (by BlayTheNinth) fixes a long-standing vanilla annoyance: breaking a double slab normally destroys both halves at once. With this mod, hitting a double slab only breaks the half you're actually looking at, leaving the other in place. The pack's config runs it in `mode = "ALWAYS"` (as opposed to only-while-sneaking or only-while-not-sneaking) with no mod compatibility overrides disabled. Single-mechanic, no other content.

## Anticipated questions
**What does it change?** It fixes the vanilla behavior where breaking a double slab destroys both halves — with KleeSlabs, hitting a double slab only breaks the half you're actually looking at, leaving the other in place.

**Does it add any blocks or items?** No — it's a single-mechanic mod with no other content; it only alters how double slabs break.

**Do I have to sneak for it to work?** No. The pack runs it in `mode = "ALWAYS"`, so partial slab-breaking applies all the time, not just while sneaking (or not sneaking).
