# Open Block Elevator Mod

A Fabric port (by farrucho) of the classic OpenBlocks Elevator: a single "Elevator Block" that, when stacked in a vertical column, lets an entity ride straight up or down between blocks in that column instead of climbing/falling normally. The pack's `openblocksconfig.properties` sets `openblocks.elevator.block.range = 20`, i.e. a column works up to 20 blocks.

This mod and **[[Quartz Elevator]]** solve the same problem (vertical block-elevators) and both are installed in this pack — Quartz Elevator's smooth variant reaches much farther (64 blocks) and is player-only, while this one caps at 20 blocks but is the more nostalgic, original OpenBlocks-style block. Having both suggests the modpack leaves it up to the builder's taste/aesthetic rather than picking one as canonical.

## How you'll use it here
Stack Elevator Blocks in a vertical column to move between floors of a multi-story base — jump to rise to the next block above, crouch to drop to the one below, skipping ladders and staircases entirely. With the pack's 20-block range each pair of blocks can be up to 20 apart, so a single hop covers a tall room or a couple of floors. Good for the OpenBlocks look; reach for [[Quartz Elevator]] instead when a shaft needs to span more than 20 blocks.

## Anticipated questions
**How far apart can the elevator blocks be?** Up to 20 blocks here (`openblocks.elevator.block.range = 20`) — space them any distance up to that and the jump/crouch teleport still connects them.

**Does it only move players?** Generally the OpenBlocks-style elevator moves any entity that stands on it and jumps, unlike Quartz Elevator's player-only variant — check in-world if you want mobs or items to ride it.
