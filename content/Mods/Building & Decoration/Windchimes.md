# Windchimes

Windchimes (by Hibi) adds exactly three hanging blocks — Iron, Bamboo, and Copper wind chimes — that sway with the wind and occasionally play a chime sound. Per the mod's own description it is deliberately unconfigurable: "this mod has no settings that can be set," and there's no config file for it in `config/`. It's a small ambient-decoration mod, nothing more.
