# Quartz Elevator

Quartz Elevator (by Aton-Kish) adds two blocks — Quartz Elevator and Smooth Quartz Elevator — that launch/lift an entity straight up when stood on, functioning like a vertical block-elevator column. The pack's config (`quartzelv.json`) sets `quartzElevatorDistance = 16` and a notably longer `smoothQuartzElevatorDistance = 64` for the smooth variant, with `mixTypes = false` (a column must be one elevator type throughout to work), `isPlayerOnly = true` (only players are lifted, not items/mobs), and particle effects on.

This mod and **[[Open Block Elevator Mod]]** do the same job — a block-based vertical elevator — with different block sets and tuning. Quartz Elevator's variants travel much farther (up to 64 blocks) than Open Block Elevator's single block (20 blocks by default here), so which one gets used in a build is really a matter of range needed and aesthetic (quartz block vs. the OpenBlocks-style elevator block).

## Anticipated questions
**What does it add?** Two blocks — Quartz Elevator and Smooth Quartz Elevator — that launch/lift an entity straight up when stood on, working as a vertical block-elevator column.

**How far do they lift?** The plain Quartz Elevator travels `quartzElevatorDistance = 16`, and the Smooth Quartz variant travels much farther at `smoothQuartzElevatorDistance = 64`.

**Will it lift mobs or dropped items?** No — `isPlayerOnly = true`, so only players are lifted.

**Can I mix the two elevator types in one column?** No — `mixTypes = false`, so a column must be a single elevator type throughout to work.

**How does it compare to Open Block Elevator?** Both do the same block-based vertical-elevator job; Quartz's variants travel much farther (up to 64) than [[Open Block Elevator Mod]]'s single block (20 by default here), so the choice comes down to range needed and aesthetic (quartz vs. the OpenBlocks-style block).
