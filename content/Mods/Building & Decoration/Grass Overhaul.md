# Grass Overhaul

Grass Overhaul (ElocinDev, Luna Pixel Studios) is a compact, focused mod (29 lang entries) that does exactly one thing well: it adds stackable, carpet-like **sod** blocks — slabs, stairs, patches, and full blocks — for every ground-cover surface in the game: Grass, Podzol, Path (dirt path), Dirt, Mycelium, Crimson Nylium, and Warped Nylium. Each surface type gets the full set (e.g. Grass Sod Block/Slab/Stairs/Patch, Podzol Sod Block/Slab/Stairs/Patch), which lets builders create thin, natural-looking terrain transitions and terraced ground detail that vanilla's single-thickness grass blocks can't achieve — a "sod patch" in particular acts like a thin carpet-style overlay rather than a full block.

No config file ships for it on this server. It's a small but high-value mod for terrain and landscaping detail work specifically — the terrain equivalent of what [[Stoneworks]] does for stone architecture.

## How you'll use it here
Use sod pieces to soften the hard edges vanilla ground blocks leave behind. Lay **sod slabs** and **stairs** to make grass, path, or podzol step down gently into terraced gardens and hillsides, and drop **sod patches** as thin carpet-style overlays to scatter natural-looking ground cover across a courtyard or forest floor. Because every surface gets the full set — Grass, Podzol, Path, Dirt, Mycelium, and both Nyliums — you can blend biome transitions (grass fading into podzol under trees, nylium creeping across a Nether build) with real height and thickness detail.

## Anticipated questions
**Which ground types can I get sod for?** Grass, Podzol, dirt Path, Dirt, Mycelium, Crimson Nylium, and Warped Nylium — each in block, slab, stairs, and patch form.

**What's a sod patch versus a sod slab?** A patch acts like a thin carpet-style overlay laid on top of a surface, while slabs/stairs are half- and stepped-height blocks for terracing — use patches for subtle ground detail, slabs/stairs for shaped terrain.
