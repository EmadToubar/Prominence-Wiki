# Decorative Blocks

Decorative Blocks (Stohun, lilypuree; Fabric port by TheWinABagel) adds 71 lang entries centered on structural-decoration pieces rather than furniture: **beam**, **palisade**, **seat**, and **support** blocks are generated per wood type (mangrove, crimson, warped, bamboo, cherry, acacia, oak, jungle, dark oak, birch, etc.), plus standalone pieces like a **big chain** and **brazier** / **soul brazier**. "Beams" and "supports" read as timber-frame architectural elements — the pieces that make exposed wooden structural framing look intentional rather than like plain log placement — while "palisade" and "seat" cover fencing and outdoor-seating use cases.

It's a compact mod (71 entries vs. Stoneworks' 582 or Chipped's thousands), so it's best thought of as a focused toolkit for timber-frame and rustic exterior detail rather than a broad decoration library. No config file ships for it on this server.

## How you'll use it here
Reach for this when a wooden build reads as flat log-and-plank boxes and needs structural character. Use **beams** and **supports** to frame exposed timber skeletons on a barn, tavern, or bridge, run a **palisade** as rough fencing around a rustic compound, drop **seats** for outdoor benching, and set a **brazier** or **soul brazier** as a fire-lit centerpiece with a **big chain** hanging above. Because pieces come per wood type (oak, birch, acacia, dark oak, cherry, crimson, warped, bamboo, etc.), you can match the framing to whatever palette the rest of the build already uses.

## Anticipated questions
**Does this add furniture like tables and chairs?** Not really — it's structural-decoration focused (beams, supports, palisades, seats, braziers). For sit-at furniture use [[Handcrafted]] instead.

**Do beams and supports come in every wood type?** They're generated per wood type across the pack's wood set, so you can generally match most vanilla and modded woods — check the recipe viewer for the exact variant you want.
