# More Mob Variants

More Mob Variants (v1.3.1, by nyuppo) doesn't add any new creature types — it purely reskins existing vanilla mobs using Minecraft 1.20's built-in variant/texture system (the same mechanism vanilla uses for cat breeds and painting art). This server's copy ships biome- and condition-based texture pools for **Cats**, **Chickens**, **Cows**, **Pigs**, **Sheep**, **Skeletons**, **Spiders**, **Wolves**, and **Zombies** — Wolves get by far the largest set (28 variant entries, expanding on vanilla's own wolf-variant vote with color pools like ashen, black, chestnut, pale, rusty, snowy, spotted, striped, and "woods," each tagged to spawn in specific biomes), while Skeletons get regional reskins including increased **sandy** (desert-biome) and **mossy** (jungle/swamp-biome) variants.

The mod's `settings.json` in this pack enables **muddy pigs** (pigs that visually get dirty after wallowing in mud, no cooldown timeout configured) and sets a **25% chance** for a baby animal to roll its own independent random variant rather than inheriting a parent's look. Because it only touches vanilla mob types, it's the "wildlife re-texturing" counterpart to mods like [[Creeper Overhaul]] and Naturalist that add genuinely new creatures — More Mob Variants just makes the vanilla ones feel less uniform across biomes.

## Anticipated questions

**Q: Does More Mob Variants add new mobs?**
A: No — it purely reskins existing vanilla mobs (Cats, Chickens, Cows, Pigs, Sheep, Skeletons, Spiders, Wolves, Zombies) using 1.20's built-in variant system, so they feel less uniform across biomes.

**Q: Which mob gets the most variants?**
A: Wolves, by far — 28 variant entries (ashen, black, chestnut, pale, rusty, snowy, spotted, striped, "woods," and more), each tagged to spawn in specific biomes.

**Q: What are muddy pigs?**
A: The mod's `settings.json` enables muddy pigs — pigs that visually get dirty after wallowing in mud (no cooldown configured). It also gives baby animals a 25% chance to roll their own random variant instead of inheriting a parent's look.
