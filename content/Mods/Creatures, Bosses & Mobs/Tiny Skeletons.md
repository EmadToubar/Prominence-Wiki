# Tiny Skeletons

Tiny Skeletons (v8.0.1, by Fuzs — the same developer behind [[Mutant Monsters]]' "Mutant Skeleton") is a small, focused mod that adds shrunken **Baby Skeleton**, **Baby Wither Skeleton**, and **Baby Stray** variants of the three vanilla skeleton types. It ships no configuration file in this pack, so it runs on default behavior — the baby versions are presumably rarer, weaker, faster-moving reskins in the same spirit as vanilla's baby zombies, rather than a threat upgrade.

The mod pairs with a separate small addon in this pack, **Mutant Skeleton Armor Tweaks** (v2.1.0, by Stalemated), which specifically patches Mutant Monsters' Mutant Skeleton to properly support crossbows — this server's `mutant_skeleton_armor_tweaks.json` has the leggings and boots equipment-effect tweaks enabled but leaves the chestplate's draw-speed buff, crossbow tweak, and skull-multishot options disabled, keeping the mutant skeleton's crossbow behavior closer to its original balance.
