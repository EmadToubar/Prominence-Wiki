# Quality-of-Life & UI Mods

## Jade
Look at any block or mob to see what it is on-screen — health, name, contents. Runs constantly without thinking about it.

## EMI
The recipe viewer — hover any item, hit the recipe/uses key, see how to make or use it. Answers almost every "how do I get X" question. Add-ons: EMI Professions, EMI Enchanting, EMI Loot, EMI Ores, Extra Mod Integrations, emi-letsdo-compat, Industrial Revolution EMI Plugin, Almost Unified (merges duplicate items/ores across mods), Polymorph (pick which mod's recipe result you get on conflicts).

## Xaero's Minimap / Xaero's World Map
The corner minimap and the full-screen map (default key M) — the standard navigation/waypoint setup.

## Distant Horizons
Renders simplified terrain far beyond normal view distance at low performance cost. Every player must install Distant Horizons 3.2.0-b client-side to see any benefit — it does nothing solo.

## FTB Quests / FTB Teams / FTB Library
FTB Quests is the Quest Book itself — see [[Getting Started]]. FTB Teams forms a party so quest progress and teleports are shared. FTB Library is shared code both run on. Quest Kill Task adds team-based kill credit. Create Questing is a Create-flavored quest-screen visual theme.

## Fabric Waystones
The fast-travel system — generate in villages, craftable, right-click to bind, teleport back from anywhere.

## Open Parties and Claims
Chunk claiming to protect builds, plus multiplayer party creation/management — per-category protection toggles (doors, chests, blocks).

## Everyday utility & fun mods (grouped)
AppleSkin, Trading Post, You're in Grave Danger (marks a death grave), Starter Kit, Fish On The Line, Ping Wheel, Clickable Advancements Mod, Show Me What You Got, No Chat Reports, Server Browser, Fancy Hotbar, Mod Menu, Do a Barrel Roll (elytra tricks), Comforts (sleeping bags/hammocks), Icarus (cosmetic wings), Runelic, PigPen, Immersive Melodies, What Are They Up To, Highlight, TreeChop, Leaves Be Gone, Extreme Sound Muffler, Veinmining, Bartering Station (automates piglin bartering), Block Runner, Villager Names.
