# Mutant Skeleton Armor Tweaks

A one-line balance mod by Stalemated: "Adds crossbow compatibility to the mutant skeleton chestplate," a boss-drop item referenced elsewhere in the vault ([[Archetypes & Builds]] notes it as a Ranger upgrade path). It's a config-gated patch rather than new content — every feature flag is independently toggleable.

On this server (`mutant_skeleton_armor_tweaks.json`) only the leggings and boots set-effects are enabled (`enable_leggings_effect`, `enable_boots_effect`); the chestplate's own multishot, draw-speed buff, and crossbow-tweak flags are all disabled (`enable_skull_multishot`, `enable_chestplate_draw_speed_buff`, `enable_chestplate_crossbow_tweak` = false) — meaning the headline crossbow-compatibility feature the mod is named for isn't actually active in this pack's tuning, only the lower-body set bonuses are.
