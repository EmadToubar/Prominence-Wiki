# Shield API

A developer-facing library mod by TheRedBrain — "Creating shields with custom models was never easier!" It provides the framework other mods (armor/weapon mods in the pack that add their own themed shields, e.g. Paladins' Kite Shields) use to register shields with bespoke models rather than reusing vanilla's single shield mesh. Like [[RangedWeaponAPI]], it has no player-facing config or in-game content of its own — it's the invisible dependency that [[Shield Overhaul]]'s parry/bash mechanics and the pack's various custom shield items sit on top of.
