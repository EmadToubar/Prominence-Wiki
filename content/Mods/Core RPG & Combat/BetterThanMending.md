# BetterThanMending

By legobmw99 — "A mod to improve the mending behavior in vanilla Minecraft." Vanilla's Mending enchantment repairs whatever single item is in your hand or hotbar when you pick up XP orbs, which is often the wrong item and encourages awkward hotbar-swap workarounds. This mod changes the targeting logic so Mending repairs more sensibly (across all equipped Mending gear rather than one arbitrary slot) — a quality-of-life fix rather than a new mechanic.

No config file is present on this server; it runs at its shipped defaults. Given how much of this pack's endgame is built around expensive, hard-to-reforge [[Gear Rarity & Reforging|rare-tier gear]], smoother Mending behavior across the whole loadout is a meaningful quality-of-life win rather than a cosmetic tweak.
